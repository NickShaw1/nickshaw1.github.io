Over the past few months, I've focused on developing my AI-assisted development skills through several courses on the Anthropic platform, each combining practical exercises with certification. Microsoft's AI-900 is also on the list, with the updated course expected shortly.

## Claude 101

Available on the [Anthropic learning platform](https://anthropic.skilljar.com/), this foundational course covers prompt design, structured problem solving and the practical application of Claude in engineering workflows. It establishes a solid grounding in prompt engineering, covering how context, specificity and instruction structure affect output quality, and how to apply those principles consistently across different use cases.

## Claude Code in Action

This course covers setting up Claude Code in the IDE and applying it to real-world delivery workflows. The exercises go beyond the basics, focusing on how to integrate Claude into iterative development: improving test coverage, reviewing and refactoring code and using AI assistance at the points in a workflow where it actually adds value rather than just as a novelty.

## Introduction to Agent Skills

This course covered the fundamentals of defining and structuring agent skills, how they enable Claude to perform specific tasks and practical approaches for integrating them into existing workflows.

### Applying AI to real delivery work

I have been applying what I've learned in real projects, particularly with **Playwright MCP** and **Claude Code**, to refine UI behaviours and build AI-assisted workflows that improve iteration speed, testing coverage and consistency.
