Software testing has always been central to how I work. Automation in particular has become an increasingly valuable part of that, streamlining the testing process and freeing up time for the work that actually requires human judgement. Playwright is one of the tools that has gained real traction in recent years, and for good reason.

As a tester, I've always valued staying ahead in a constantly evolving field. I've used many tools over the years, but recently decided to go deeper on test automation, with a focus on JavaScript, TypeScript and Python, alongside building out my Playwright skills in VS Code.

I want to use this site to document that process.

To do that, I needed to build the site first. My professional career has been focused on the testing side rather than front-end development, so this was a deliberate step into new territory. The site has been built from scratch in React, TypeScript and Vite, and has been a genuinely enjoyable project to work through.

Learning through YouTube has been a useful complement to hands-on practice. Here are the channels I've found most helpful so far.

1. [Web Dev Simplified](https://www.youtube.com/@WebDevSimplified)
2. [Programming with Mosh](https://www.youtube.com/@programmingwithmosh)
3. [ProgrammingKnowledge](https://www.youtube.com/@ProgrammingKnowledge)
4. [SuperSimpleDev](https://www.youtube.com/@SuperSimpleDev)
5. [Automation Step by Step](https://www.youtube.com/@RaghavPal)
6. [Flux Academy](https://www.youtube.com/@FluxAcademy)
7. [Bro Code](https://www.youtube.com/@BroCodez)
8. [The Website Architect](https://www.youtube.com/@thewebsitearchitect)

If you know of other channels worth exploring across web development or test automation, they are always welcome.
